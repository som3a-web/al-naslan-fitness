# Al Naslan Fitness Center

Premium client-facing website for **Al Naslan Fitness Center** in Sharjah, UAE. The site presents the gym experience, facilities, programs, memberships, classes, nutrition, swimming, kids academy, analytics, and free trial booking in one polished responsive interface.

## Stack

- **Next.js 14** with the App Router
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Recharts**
- Custom particle effects, 3D brand scene, and responsive UI components

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm start
```
